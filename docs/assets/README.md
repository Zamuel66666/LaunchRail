# Documentation assets

Store recruiter- and user-facing screenshots, diagrams, GIFs, and short demonstration assets here when the depicted milestone is complete.

Before committing an asset:

- Use a descriptive name such as `deployment-live-build-logs.png`.
- Crop irrelevant desktop content and keep text legible.
- Remove tokens, secrets, personal data, private repository URLs, and local machine identifiers.
- Prefer source-controlled Mermaid for architecture diagrams that do not require raster imagery.
- Link the asset from the README or the document that explains what it proves.
- Do not add empty-form or unfinished-interface screenshots merely to make the repository look active.
